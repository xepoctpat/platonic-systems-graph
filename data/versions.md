## Backbone

### V1 — Core Platonic Spine (7 stages)

The Timaean–Republic–Symposium axis as a single directed hierarchy:

1. **The Good** (beyond being)
2. **Intelligible Paradigm** (the Living Creature / Forms as model)
3. **Demiurge** (divine craftsman / Nous)
4. **World Soul** (same / other / being)
5. **Ordered Time** (moving image of eternity; celestial order)
6. **Receptacle** (chōra / necessity / wandering cause)
7. **Becoming** (particulars, mortal living things)

Eros is not a numbered stage. It is the return operator that closes the spine.

### V2 — Mystical & Occult Domain

How later esoteric systems **root** in the spine (gold), **mirror** it (cyan), **invert** it (magenta), **return** along it (green), or **shatter** it (red).

Principal clusters: Neoplatonism, Hermetica / Chaldean Oracles / theurgy, Gnosticism (Pleroma–Sophia–Ialdabaoth), Lurianic Kabbalah (Ein Sof–Sefirot–Shevirah–Tikkun), alchemy.

### V3 — Scientific & Philosophical Domain

The same spine read as a proto-systems theory: attractors, governors, noise, information, entropy / negentropy, symmetry breaking, self-organization.

Principal clusters: Aristotle, Stoic logos, Spinoza, Kant, Hegel, Whitehead, thermodynamics, cybernetics (Wiener / Ashby), complexity.

### V4 — Religious & Mythological Domain

Craftsman gods, cosmic order, creation-from-void, incarnation, mystery ascent, and two major non-craftsman contrasts (Brahman; Śūnyatā).

Principal clusters: Ptah / Ma'at, Genesis, Johannine Logos / Incarnation, Orphic Dionysus, Eleusinian-type ascent, Sāṃkhya, Zoroastrian dualism.

## Cross-cuts

### V5 — Cross-Domain Lateral Interplay

Hybrid and isomorphic **lateral** links that do not go through the Platonic spine: e.g. Logos family (Stoic / Hermetic / Johannine), restoration family (Tikkun / opus / theurgy / Eros), fall family (Shevirah / Orphic sparagmos / Sophia), highest-principle family (Good / One / Ein Sof / Brahman).

### V6 — Cybernetic Dynamics Overview

The spine recoded as a control system:

| Function | Node |
|---|---|
| Attractor / reference | The Good |
| Controller / Nous | Demiurge |
| Homeostat / governor | World Soul |
| Clock / reference trajectory | Ordered Time |
| Disturbance / noise | Receptacle |
| Plant / output | Becoming |
| Negative feedback | Eros, Tikkun, theurgy, negentropy |
| Positive feedback | entropy, Shevirah, Gnostic fall, Statesman run-down |

## Critical tensions

Each of V7–V11 is a **magenta** pair (sometimes with a cyan cousin) plus the gold / green / red edges that make the contrast operational.

### V7 — Plato’s Demiurge vs Gnostic Demiurge

Benevolent craftsman who looks to an eternal model and is “without jealousy” (Timaeus 29e) versus Ialdabaoth / the archontic craftsman who fabricates a prison and does not know the Pleroma.

### V8 — Matter as Receptacle vs Prison

Chōra as nurse, space, and necessary condition of becoming versus matter as tomb / kenoma / soma-sēma. Same “below” of the hierarchy; opposite soteriology.

### V9 — Ordered Time vs Fallen Time

Time as the moving image of eternity (generated *with* the heavens, therefore ordered) versus exile-time, irreversible fall, apocalyptic rupture, and the Statesman myth of cosmic reversal when the steersman lets go.

### V10 — Cosmic Love vs Escape Gnosis

Symposium / Timaean *erōs* and elemental *philia* as the force that binds and returns the cosmos versus a gnosis whose end is *exit* from the cosmos.

### V11 — Status of the Highest Principle

Is the summit the Good (source of being, still related to a cosmos it makes intelligible), Plotinus’s One, Ein Sof, the Gnostic Unknown Father, a personal creator, Brahman, or emptiness? Cyan for structural analogy; magenta for theological inversion.
